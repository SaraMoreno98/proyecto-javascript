Este proyecto es una web personal. El sitio web muestra mi trabajo, mis habilidades, y proporciona información sobre mis servicios.

Características
- Diseño responsivo para móviles, tabletas y ordenadores de sobremesa.
- Secciones de contenido dinámico que incluyen un escaparate de portafolio y servicios
- Elementos interactivos como deslizadores y un carrito de la compra para los servicios
- Efecto de paralaje en la imagen del banner
- Fuentes y combinación de colores personalizados

Tecnologías utilizadas
- HTML5
- CSS3 (con propiedades personalizadas para la tematización)
- JavaScript
- Técnicas de diseño web adaptable
- Iconos Font Awesome

Secciones clave
- Home/Banner con efecto parallax
- Portafolio con sliders de imágenes
- Sección de servicios con carrito de la compra interactivo
- Sección Acerca de mí
- Resumen de habilidades y capacidades
- CV/Portafolio descargable
- Información de contacto y enlaces a redes sociales
